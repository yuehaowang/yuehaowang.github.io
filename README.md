# Yuehao's Homepage

Personal academic website of [Yuehao Wang](https://yuehaowang.github.io/).

- Static pages built with HTML, CSS, and JavaScript.
- Please do not copy this repository directly.

## Typography

The website uses [Newsreader](https://github.com/productiontype/Newsreader), designed by Production Type and served through Google Fonts. Copyright 2020 The Newsreader Project Authors. Newsreader is licensed under the [SIL Open Font License 1.1](https://github.com/google/fonts/blob/main/ofl/newsreader/OFL.txt), separately from the website's content license.

Newsreader is loaded from Google Fonts, with Baskerville and Georgia as system fallbacks. No font files are bundled in this repository.
